# Shoebox

A self-hosted photo album: albums and collections, photo indexes and slideshows, users and
groups, passkey and password sign-in, and four kinds of album visibility — public, unlisted,
password-protected, and restricted to chosen users and groups.

Photo metadata — where and when a photo was taken, and with what — is stripped from every image
Shoebox serves and kept beside it, so who may see it is a setting rather than an accident.

Named after where most people's photos actually lived for decades. Its slideshows are
[Clack](https://github.com/wisborg/clack).

## Status

Planning. Nothing is built yet. **[docs/plan.md](docs/plan.md) is the design this will be built
to**, with the reasoning behind each decision and the alternatives that were rejected.
